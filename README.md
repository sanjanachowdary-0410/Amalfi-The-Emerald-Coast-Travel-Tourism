Amalfi & The Emerald Coast — Travel & Tourism Website

A responsive, modern single-page travel and tourism web application showcasing Amalfi & The Emerald Coast, built with semantic HTML5, Tailwind CSS, and vanilla JavaScript.

Live Demo: https://sanjanachowdary-0410.github.io/Amalfi-The-Emerald-Coast-Travel-Tourism/

Overview

The application presents a coastal sanctuary experience blending Mediterranean cliffs, emerald coves, and highland ridge trails. It is structured for smooth navigation across desktop, tablet, and mobile screens, with interactive detail modals, a filterable photo lightbox gallery, and an interactive trip booking form.

Key Sections & Features

Sticky Navigation & Hero Section:

Fixed navigation bar (About, Places, Packages, Activities, Gallery, and Book Trip) with a responsive mobile drawer menu.

Full-bleed coastal hero image with subtle motion and gradient scrims, featuring the headline "Discover the Beauty of the World", an introductory description, Explore Now and Book Your Trip call-to-action buttons, and a quick-stats strip (300+ sunny days, 48 km shoreline, 12th C. maritime heritage, and 4.9 ★ rating).

About the Destination:

Editorial narrative and layered coastal photography highlighting four pillars: Rich History & Heritage, Warm Coastal Culture, Balanced Year-Round Climate, and Iconic Landmarks & Coves.

Popular Places to Visit:

Interactive cards for six destinations (Positano Cliffside Sanctuary, Emerald Grotto & Cala Verde, Ravello Terrace Gardens, Path of the Gods Ridge, Atrani Harbor & Lemon Groves, and Li Galli Marine Reserve) showing location, best time to visit, short description, and a View More button that opens a detailed modal with highlights, local tips, and direct booking selection.

Travel Packages:

Four curated packages—Weekend Getaway (3 Days / 2 Nights, $690), Adventure Package (5 Days / 4 Nights, $1,240), Family Vacation (6 Days / 5 Nights, $1,580), and Luxury Tour (7 Days / 6 Nights, $2,890)—each listing duration, pricing, included facilities, sample itinerary highlights in the Explore Package modal, and pre-filled booking support.

Activities & Experiences:

Six experience cards covering Mountain Trekking, Beach Activities, Camping, Sightseeing, Boating, and Wildlife Exploration.

Photo Gallery:

Responsive visual grid with category filter tabs (All, Landscapes, Attractions, Culture, Food, Adventure), hover captions, and a full-screen lightbox modal with previous/next navigation.

Interactive Booking Section:

Form collecting Full Name, Email Address, Phone Number, Destination / Experience, Travel Date, Number of Travelers, and optional notes, complete with validation feedback and an instant booking summary confirmation view.

Built With

HTML5

Tailwind CSS (via CDN with custom color palette, typography, and shadow utilities)

Google Fonts (Cormorant Garamond display serif and Inter UI/body sans)

Vanilla JavaScript (ES6+) for dynamic card rendering, modal dialogs, gallery filtering, scroll-reveal animations, and form validation

Running Locally

Clone the repository:

git clone https://github.com/sanjanachowdary-0410/Amalfi-The-Emerald-Coast-Travel-Tourism.git


Navigate into the project directory:

cd Amalfi-The-Emerald-Coast-Travel-Tourism


Open index.html in your web browser (or serve it with any static local server such as VS Code Live Server or npx serve).
